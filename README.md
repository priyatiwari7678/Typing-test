🚀 Features

⏱️ Adjustable Timer – Choose from 15s, 30s, 60s, or 120s sessions

🧾 Multiple Paragraph Sets – 6 fun short stories that change with each test

📊 Live Statistics – Real-time updates of WPM, accuracy, errors, and progress bar

✍️ Typing Box Display – See your typed text live as you type

🔁 Next Paragraph Button – Instantly switch to a new story for practice

💾 Local Storage High Score (optional upgrade) – Save your best performance

🎨 Vibrant & Responsive UI – Clean, readable design for all screen sizes

🧠 How It Works

Click the Start button to begin the test.

Type the text shown above in the input box.

Your speed, accuracy, and progress update live.

When time runs out, your WPM score is displayed.

Click Next Paragraph to try a different story and improve your performance!
